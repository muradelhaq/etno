Kebijakan Privasi

E-Modul Etnosains Makanan Tradisional Berbasis Fermentasi

Package ID: com.etnosains.e_modul_etnosains • Terakhir Diperbarui: September 2026
Selamat datang di aplikasi E-Modul Etnosains. Kami berkomitmen penuh untuk melindungi privasi siswa, pendidik, dan seluruh pengguna kami. Dokumen ini menguraikan bagaimana data dikumpulkan, digunakan, dilindungi, dan hak Anda untuk menghapus data tersebut sesuai standar perlindungan data dan Google Play Developer Policy.

📋 1. Informasi yang Kami Kumpulkan

Aplikasi ini adalah media edukasi sains interaktif untuk jenjang sekolah. Data yang kami kumpulkan bersifat minimal dan hanya digunakan untuk mendukung pengalaman pembelajaran:

Identitas Belajar Siswa
Nama lengkap siswa, kelas / rombongan belajar, dan asal sekolah untuk personalisasi sertifikat serta rekapitulasi nilai guru.
Progres & Evaluasi Belajar
Capaian poin pengalaman (XP), penyelesaian modul fermentasi, jawaban kuis literasi sains PISA, dan hasil observasi lab virtual.

🔒 Data yang TIDAK Kami Kumpulkan

Kami TIDAK mengumpulkan data lokasi GPS presisi, kontak telepon, galeri foto pribadi, rekaman mikrofon/kamera, nomor identitas kependudukan, maupun informasi keuangan. Aplikasi ini 100% Bebas Iklan komersial (Ad-Free) dan bebas dari pelacak iklan pihak ketiga.

🎯 2. Tujuan Penggunaan Data

Data yang dikumpulkan semata-mata dimanfaatkan untuk keperluan akademik dan edukasi:

  • Menyimpan progres pembelajaran mandiri siswa agar materi tidak tereset saat aplikasi ditutup.
  • Memberikan umpan balik instan (pembahasan) pada kuis evaluasi sains PISA dan simulasi laboratorium virtual.
  • Memfasilitasi guru/pendidik dalam memantau ketercapaian kompetensi sains siswa secara kontekstual.

🛡️ 3. Penyimpanan dan Keamanan Data

  • Penyimpanan Lokal: Data progres disimpan secara lokal di memori perangkat melalui penyimpanan terisolasi (SharedPreferences).
  • Enkripsi Transit (Cloud): Apabila perangkat terhubung internet, data disinkronkan ke backend database kami (Supabase PostgreSQL) menggunakan enkripsi tingkat tinggi HTTPS / TLS 1.3.
  • Tanpa Penjualan Data: Kami tidak pernah menjual, menyewakan, atau membagikan data siswa kepada pihak ketiga untuk kepentingan komersial maupun periklanan.

🗑️ 4. Hak Pengguna & Penghapusan Akun (Account & Data Deletion)

Sesuai kebijakan Google Play Store, kami memberikan hak penuh kepada pengguna untuk menghapus akun profil dan seluruh data pribadinya:

  1. Penghapusan Mandiri di Aplikasi (In-App):
    Pengguna dapat menghapus profil dan seluruh data belajarnya kapan saja langsung dari dalam aplikasi. Buka menu profil di aplikasi dan klik tombol "Hapus Profil & Reset Riwayat Belajar". Tindakan ini seketika menghapus data lokal dan menghapus seluruh catatan di database server.
  2. Permintaan Penghapusan via Web / Email (Web Request):
    Jika siswa, orang tua, atau pihak sekolah menghendaki penghapusan akun tanpa membuka aplikasi, Anda dapat mengajukan permohonan penghapusan dengan menyertakan nama dan asal sekolah ke:
    • Email: rafidiaulhaq360@gmail.com (Subjek: Permintaan Hapus Akun E-Modul)
    • GitHub Issues: github.com/muradelhaq/etno/issues

Cakupan Data yang Dihapus: Nama, kelas, sekolah, ID akun, serta seluruh histori kuis, poin XP, dan catatan eksperimen sains. Permintaan via web akan diproses dan dihapus permanen dalam waktu maksimal 3 x 24 jam kerja (Zero Data Retention).

👨‍🎓 5. Privasi Siswa & Anak-Anak

Aplikasi ini dirancang untuk jenjang pendidikan SMP dan SMA (rentang usia 13 tahun ke atas). Konten aplikasi murni materi bioteknologi tradisional nusantara (seperti tempe, oncom, tape ketan, terasi, dan brem) yang disusun untuk tujuan literasi sains tanpa memuat materi berbahaya atau tidak pantas.

🔄 6. Pembaruan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu sesuai pengembangan fitur atau kepatuhan terhadap regulasi baru. Setiap perubahan akan diumumkan dan dicantumkan pada halaman ini.
