# Kebijakan Privasi (Privacy Policy)
**E-Modul Etnosains Makanan Tradisional Berbasis Fermentasi**  
*Terakhir Diperbarui: September 2026*

Selamat datang di aplikasi **E-Modul Etnosains** (`com.etnosains.e_modul_etnosains`). Kami menghargai privasi siswa, pendidik, dan pengguna kami. Dokumen Kebijakan Privasi ini menjelaskan bagaimana data dikumpulkan, digunakan, disimpan, dan dilindungi saat Anda menggunakan aplikasi pembelajaran interaktif ini.

---

## 1. Informasi yang Kami Kumpulkan

Aplikasi E-Modul Etnosains dirancang khusus sebagai media edukasi sains (etnosains fermentasi makanan tradisional seperti tempe, tape, dan oncom). Data yang kami kumpulkan meliputi:

1. **Identitas Profil Belajar Siswa**:
   - Nama Lengkap Siswa
   - Kelas / Rombongan Belajar (Rombel)
   - Asal Sekolah
2. **Aktivitas & Progres Belajar**:
   - Status penyelesaian modul dan slide materi
   - Capaian poin pengalaman (*Experience Points* / XP)
   - Jawaban kuis pilihan ganda (evaluasi sains PISA)
   - Refleksi kasus sains dan catatan proyek inovasi makanan tradisional
   - Riwayat simulasi eksperimen laboratorium virtual

> [!NOTE]
> **Data yang TIDAK Kami Kumpulkan:**  
> Kami **TIDAK** mengumpulkan data lokasi GPS presisi, kontak telepon, galeri foto/video pribadi, mikrofon, nomor identitas kependudukan rahasia, maupun data keuangan/transaksi berbayar. Aplikasi ini bebas iklan (*ad-free*).

---

## 2. Tujuan Penggunaan Informasi

Informasi yang dikumpulkan hanya digunakan untuk kepentingan pembelajaran:
- Menyimpan kemajuan belajar mandiri siswa agar tidak tereset ketika aplikasi ditutup.
- Memungkinkan guru/pendidik melihat rekapitulasi capaian dan asesmen pemahaman konsep sains siswa.
- Memberikan umpan balik langsung (*instant feedback*) pada latihan kuis dan eksperimen virtual lab.

---

## 3. Penyimpanan dan Keamanan Data

- **Penyimpanan Lokal:** Data riwayat belajar disimpan secara lokal di memori perangkat pengguna melalui penyimpanan aman (*SharedPreferences*).
- **Sinkronisasi Cloud:** Apabila perangkat terhubung ke internet, data progres disinkronkan ke backend database terenkripsi (Supabase PostgreSQL) menggunakan koneksi aman **HTTPS / SSL (TLS 1.3)**.
- **Tanpa Pihak Ketiga Komersial:** Kami tidak menjual, menyewakan, atau membagikan data siswa kepada perusahaan iklan atau pihak ketiga untuk kepentingan komersial.

---

## 4. Hak Pengguna & Penghapusan Data (*Account & Data Deletion*)

Kami menjunjung tinggi hak pengguna atas data pribadinya:
1. **Reset Mandiri di Aplikasi:**  
   Pengguna dapat menghapus seluruh data profil dan riwayat belajar kapan saja secara langsung dari dalam aplikasi melalui menu **"Reset Data & Hapus Profil"** (tersedia di menu Drawer / Form Profil).
2. **Penghapusan Data dari Server:**  
   Jika siswa atau pihak sekolah menghendaki seluruh data riwayat siswa dihapus dari server backend, Anda dapat mengajukan permintaan penghapusan data dengan mencantumkan nama dan asal sekolah melalui:
   - **Email:** `rafidiaulhaq360@gmail.com`
   - **GitHub Issue:** [https://github.com/muradelhaq/etno/issues](https://github.com/muradelhaq/etno/issues)

Permintaan penghapusan data server akan diproses dalam waktu maksimal 3x24 jam kerja.
